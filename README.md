# Shoxrux portfolio

## Ishga tushirish

1. VS Code terminalini oching.
2. `npm start` buyrug‘ini yozing.
3. Brauzerda `http://localhost:3000` manzilini oching.

## Fayllar vazifasi

- `public/index.html` — saytning matni va tuzilishi.
- `public/style.css` — dizayn va telefonga moslashuv.
- `public/script.js` — mobil menyu va joriy yil funksiyasi.
- `server.js` — Node.js orqali sayt fayllarini brauzerga yuboradi.
- `package.json` — loyiha nomi va ishga tushirish buyrug‘i.
